# 终端下载工具使用说明

桌面客户端已新增：交付目录中双击`三平台下载器.exe`，可在“更改位置”选择保存目录，在“我的账号”登录自己的三平台账号。便携版详情见`便携版使用说明.txt`；终端用法仍保留如下。

在 PowerShell 中进入 `D:\Work\浏览器插件分析` 后运行。

## 终端交互（推荐）

双击项目根目录 `启动下载工具.cmd`。粘贴分享文案，支持多行，输入空行开始下载。完成后可以继续粘贴下一批，不必重启。

常用命令：

- `:login 1`：登录抖音；`:login 2`：小红书；`:login 3`：B站。
- `:dir D:\我的下载`：设置并记住保存目录（支持中文、空格路径）。
- `:open`：打开保存文件夹。
- `:retry`：重试上一批失败链接。
- `:help`：帮助；`:quit`：退出。

下载遇到临时网络错误最多自动重试两次；60秒无数据触发超时。Ctrl+C 中断整个终端应用，保留 `.part` 文件；再次提交相同链接可续传（服务器支持时）。

保存目录配置位于 `.runtime\settings.json`，不包含登录凭据。带参数的旧命令行用法仍保留，`-o` 可以覆盖本次目录。

## 可选旧窗口

也可以运行 `npm run ui`，再访问 `http://127.0.0.1:17856`。

旧窗口的登录按钮仍可用。终端登录命令需要在完成网页登录后返回终端按 Enter；读到 Cookie 仅代表存在会话数据，有效性以解析结果为准。

小红书已验证一条图文笔记下载，静态解析缺详情时会启动专用Edge读取页面加载出的笔记数据。遇到登录或安全验证提示，使用 `:login 2` 手动完成后再下载。抖音及小红书视频尚未真实下载验收。

## 直接粘贴

```powershell
npm start
```

粘贴抖音、B站或小红书的分享链接/整段分享文案；可以连续粘贴多行，最后输入一个空行开始下载。文件默认保存到 `下载结果`。

## 命令行传入

```powershell
npm start -- "https://www.bilibili.com/video/BV..."
npm start -- "链接1" "链接2" -o "D:\我的下载"
```

只解析信息、不下载：

```powershell
npm start -- --info-only "链接"
```

## 登录以取得较高清晰度

```powershell
npm start -- --login bilibili
npm start -- --login douyin
npm start -- --login xiaohongshu
```

在打开的独立 Edge 窗口中登录，回到终端按 Enter。登录状态只保存在项目忽略提交的 `.runtime\edge-profile` 中，不会写入开发文档或打印 Cookie。B站已实测登录后可下载并合并 1080P。

工具默认调用 `D:\Software\ffmpeg\bin\ffmpeg.exe` 合并 B站音视频轨；同名成品会自动追加 `(1)`，不会覆盖旧文件。
