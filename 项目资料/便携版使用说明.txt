三平台下载器 0.3.2 RC

启动：双击“三平台下载器.exe”。整个文件夹一起保留或移动，不要只复制 EXE。

下载：在“媒体下载”粘贴链接或整段分享文案，点击“开始下载”。支持多链接串行下载、进度显示、失败重试和同名文件编号。

保存位置：点击“更改位置”选择文件夹。设置保存在程序旁“数据/settings.json”，下次启动继续使用。默认保存到程序旁“下载结果”。

自己的账号：进入“我的账号”，分别点击抖音、小红书或B站登录，在官方 Edge 页面扫码/输入账号；完成后返回客户端点“检查登录”。会话存在不代表下载权限一直有效，失效时重新登录。

便携数据：“数据”目录包含登录会话、客户端缓存和设置。分享程序给别人时不要带上自己的“数据”目录。更新程序时保留自己的“数据”与“下载结果”；自定义目录的文件不受程序更新影响。

依赖：包内已带 Node.js 与 FFmpeg，无需另行安装。Windows 需要 Edge 和 WebView2 Runtime。本机已具备；其他机器尚未验证。

验证状态：Tauri/Vue/Vite 构建、EXE后台预检、中文空格自定义目录、小红书图文真实下载和8项测试通过。原生目录选择与三平台实际账号登录的完整交互未完成最终验收；抖音、小红书视频仍待实际链接验证，故标为 RC 试用版。

构建：源码项目中运行 npm run portable（直接生成便携目录，不压缩）。

在线更新：进入“程序更新”点击“检查更新”；发现新版后点击“下载更新并重启”。来自公开仓库 Nan-WenYuan/MediaDownloader，无需 GitHub 登录。RC 试用版也会显示。下载和 SHA-256 校验通过才替换 EXE、后端及有变化的运行时文件，不修改“数据”、下载目录和保存位置。失败时检查程序旁 .media-update 中的 failed.txt；回滚文件保留在对应 backup 目录中，确认新版本正常后可删除已完成的对应更新目录。

GitHub 无压缩发布：Release 附各独立程序文件、update-manifest.json 与 download-portable.ps1。首次下载请将 download-portable.ps1 保存到本机，用 PowerShell 运行以组装完整便携文件夹，不要只下载 EXE。脚本不会覆盖已有目录。
