## 桌面便携版 0.2.0 RC

- `desktop`为Vue/Vite前端，`src-tauri`为桌面壳与原生目录选择，`src/desktop-worker.mjs`复用平台解析和下载。Tauri通过私有标准输入输出通信，不开放HTTP接口；后台与FFmpeg隐藏启动。
- 包含固定名称`三平台下载器.exe`、`runtime`、`backend`；首次运行在包旁创建`数据`和`下载结果`。目录设置、专用Edge账号配置、WebView缓存均使用便携数据目录。发布时不复制开发机账号或用户下载文件。
- 版本统一为0.2.0；新增桌面流程采用次版本升级。交付`交付/三平台下载器-0.2.0.261001_134903_RC`，直接文件夹，不生成压缩包。打包脚本`项目资料/工具/package-portable.mjs`使用北京时间和现有版本配置，`npm run portable`可复现；重新打包不自动复制旧配置，用户升级须保留数据目录。
- Windows release构建、包内EXE无界面后台预检通过；初版实际桌面窗口已显示并通过控件树检查。8项测试通过，其中含IPC、中文空格下载位置及跨启动设置持久化。包内Node实际下载小红书图文样例到中文空格目录，235082字节WebP检查通过。
- 原生截图采集超时，随后用户按Escape停止桌面操作；已停止界面自动操作。最终原生目录选择与三平台账号登录全过程、最终包的完整GUI下载流程未完成验收，因此交付类型为RC。其他机器的Edge/WebView2依赖未验证。
